# Git Learning Wiki

An agent-portable, source-linked learning bundle for understanding Git from everyday commands down to its data model. Format: [Google Open Knowledge Format v0.2](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md).

## Start here

* [Agent guide](/agent-guide.md) - How people and agents should read, update, and teach from this bundle.
* [Learning path](/git-learning-path.md) - A staged route from basic workflow to Git internals.
* [Research source map](/git-source-map.md) - Primary-source reading list organized by topic.

## Core concepts

* [Working tree, index, and repository](/git-working-tree-index-repository.md) - The three areas involved in recording changes.
* [Objects, commits, and references](/git-objects-and-history.md) - How Git stores content and names history.
* [Branches and merges](/git-branches-and-merging.md) - Branch pointers, HEAD, and combining histories.

## Practice

* [Practice repository guide](/git-practice-guide.md) - Safe exercises using the local `~/git-practice` repository.

## Bundle conventions

Concepts use OKF frontmatter. Until a person reviews a concept, it remains `status: draft` and has no `verified` field. Links are bundle-root-relative, as recommended by OKF. See [the agent guide](/agent-guide.md) before editing.
