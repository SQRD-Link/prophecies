# SEO
Covers questions and optimization guidance related to search engine visibility, domain authority transfer, redirects for SEO, and backlink management strategies during domain migration.

# Wordpress
Covers questions and issues related to WordPress site design, theme styling, layout customization questions, REST API, plugin usage, Redis and third-party automation mapping issues. also covers troubleshooting and setup of WordPress API connections, automation tools (Zapier, Make, n8n) and plugin-based integrations with third-party AI services such as Claude or ChatGPT.
# Microsoft 365
Covers questions and troubleshooting related to integrating Microsoft 365 services with web hosting environments, including email setup, domain linking, and shared management.
# Cloud ai integrations
Covers integration issues between hosted websites or WordPress and external AI agents or APIs like Claude, ChatGPT or similar, including MCP setup, authentication, and automation workflows.
# Caching
Covers identification and troubleshooting of caching-related issues including browser cache, server cache, LiteSpeed cache, and CDN cache behavior.
# Abuse
Covers copyright, trademark, or other legal complaints related to hosted domains and content, including DMCA or abuse reports and provider obligations.
# Plesk
Covers questions about creating, modifying, or managing user accounts, roles, and permissions, domain management, webspace management and all other things related to hosting management within the Plesk control panel such as (S)FTP issues related to configuring domain or URL redirects (301/302) including via .htaccess, control panels, or domain aliases.
# Server configuration
Covers enabling, configuring, or troubleshooting Node.js on hosted environments, including setup for specific domains or subdomains. requests involving backend or server-level configuration changes that cannot be altered via the hosting control panel, such as log management or server settings adjustments.
# Database
Covers issues relating specifically to database errors, imports, exports, structure, or permission problems independent of general website hosting issues.
# Ssl
Covers SSL/TLS certificate installation, renewal, validation errors, HTTPS redirects, and mixed content issues when configuring secure websites.
# chitchat
Covers casual, non-support conversations where the user does not request assistance with any hosting or technical issue.
# Account management
Covers requests related to verifying, changing, or cancelling all products or services associated with a user account, including account termination confirmations.
# Affiliates
Covers inquiries and proposals related to affiliate or partnership programs, including recruitment, commissions, referrals, and partnership management.
# Escalation
Covers cases where the user requests to be connected or escalated to a human agent for urgent or specialized assistance.
# General questions
General user inquiries unrelated to Cloud86 products or services, where the agent can redirect users appropriately.
# Security
Questions about blocking malicious or unwanted traffic, spam prevention, firewall filtering, CAPTCHA usage, brute-force protection, and other website security controls.
# Login problemen (2FA)
Inability to log in to any Cloud86 portal, two-factor authentication failures or resets, password recovery, and account lockouts. Scope is limited to authentication — not what the user does once logged in.
# Facturatie
Covers invoices, payment failures, refund requests, payment method changes, credit balance, VAT questions, account suspension due to non-payment, purchase orders, invoices, supplier billing instructions, and financial process communications that must be routed to finance or procurement teams.
# Managed VPS
VPS-specific topics: server management firewall rules, SSH access, OS-level questions, resource scaling, and server-side software installation for managed VPS products.
# Sales/kortingen
Pricing inquiries, promotional codes, discount eligibility, new customer offers, and pre-sales questions not tied to a specific existing product or account.
# Pakketten
Hosting plan comparisons, upgrade or downgrade requests, plan features, storage/bandwidth limits, and questions about what is or is not included in a specific package.
# Verhuisservice
Assisted migration of websites, email, or databases from another provider to Cloud86, including migration planning, file transfers, and DNS cutover coordination.
# Storingen/status
Reported or confirmed service outages, infrastructure incidents, scheduled maintenance notifications, and status page inquiries. Use when the issue affects multiple customers or is platform-wide.
# Performance
Slow loading times, high resource usage (CPU/memory/disk I/O), caching configuration, PHP version or limits, database query performance, and CDN setup. Excludes full outages (→ Storingen/status).
# Back-ups
Backup availability, restore requests, backup frequency or retention questions, and failures in automated backup processes.
# Website/problemen
Covers troubleshooting and recovery of lost or overwritten websites, including file restoration, database reconnection, Website downtime, HTTP errors (4xx/5xx), CMS issues, plugin/theme conflicts, SSL certificate errors, FTP/SFTP access, file permissions, and .htaccess problems. file upload size limits and backup recovery steps within hosting environments.
# E-mail
Email delivery failures, spam/junk issues, SPF/DKIM/DMARC setup, mailbox configuration, IMAP/POP3/SMTP settings, email quotas, and webmail access problems. also covers detection, handling, and routing of spam or promotional messages within the support ticketing system.
# DNS
DNS record management (A, AAAA, CNAME, MX, TXT, NS, SRV), propagation delays, nameserver changes, DNSSEC, TTL configuration, and DNS-related resolution failures. Excludes email delivery issues caused by DNS (→ E-mail).
# Domeinnamen
Domain registration, transfers (EPP/auth codes), renewals, expiry, WHOIS data, domain ownership changes, TLD-specific rules, and domain redemption or deletion lifecycle.
